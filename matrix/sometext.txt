Собственно -- запускайте файл alg.m (здесь он основной MATLAB-овский файл)

для создания матриц используйте это: 

n = 500;
M1 = rand(n);
M2 = rand(n);
save('M1.dat', 'M1', '-ascii');
save('M2.dat', 'M2', '-ascii');

Создадутся тестовые матрицы размером 500 x 500 

Трёхдиагональная матрица с диагональным преобладанием создается вот так: 

a = -1 * ones(n,1);   % поддиагональ
b = 4 * ones(n,1);    % главная диагональ
c = -1 * ones(n,1);   % наддиагональ
T_full = diag(b) + diag(a(2:n), -1) + diag(c(1:n-1), 1);
save('T.dat', 'T_full', '-ascii');
