## Структура проекта

### Исходные файлы:
- **Timer.h/cpp** - Утилиты для измерения времени выполнения
- **Matrixes_Generator.cpp** - Генератор случайных матриц для тестирования
- **Sum_Matrices_Sequential.cpp** - Оптимизированное сложение матриц
- **Multiply_Matrices.cpp** - Высокопроизводительное умножение матриц
- **GenerateMatrix.cpp** - Генератор трехдиагональных матриц
- **InvertMatrix.cpp** - Параллельная инверсия трехдиагональных матриц

## Описание программ

### 1. Timer (Timer.h/cpp)
**Назначение**: Утилита для точного измерения времени выполнения кода.

### 2. Matrixes_Generator.cpp
**Назначение**: Генератор случайных матриц размером 2000×2000 для тестирования.

### 3. Sum_Matrices_Sequential.cpp
**Назначение**: Высокоскоростное сложение двух матриц с использованием AVX-векторизации.

### 4. Multiply_Matrices.cpp
**Назначение**: Оптимизированное умножение матриц с использованием BLAS и многопоточности.

### 5. GenerateMatrix.cpp
**Назначение**: Генератор трехдиагональных матриц для алгоритма инвертирования.

### 6. InvertMatrix.cpp
**Назначение**: Параллельная инверсия трехдиагональных матриц с использованием OpenMP.

## Технологии ускорения

- **AVX/AVX2 векторные инструкции** - обработка нескольких данных одной командой
- **OpenMP многопоточность** - параллельное выполнение на нескольких ядрах CPU
- **Prefetching** - предварительная загрузка данных в кэш
- **Выравнивание памяти** - оптимальное расположение данных для процессора
- **OpenBLAS** - высокооптимизированные реализации линейной алгебры

## Компиляция

Скомпилируйте все программы последовательно:

```bash
# Генератор случайных матриц
g++ -O3 -mavx2 Matrixes_Generator.cpp -o Matrixes_Generator

# Генератор трехдиагональных матриц
g++ -O3 -mavx2 GenerateMatrix.cpp -o GenerateMatrix

# Сложение матриц (AVX-оптимизированное)
g++ -O3 -mavx2 Sum_Matrices_Sequential.cpp Timer.cpp -o Sum_Matrices_Sequential

# Умножение матриц (OpenBLAS + OpenMP)
g++ -O3 -mavx -mavx2 -mfma -fopenmp Multiply_Matrices.cpp Timer.cpp -lopenblas -o Multiply_Matrices

# Инверсия матриц (OpenMP + AVX)
g++ -O3 -mavx -mavx2 -mfma -fopenmp InvertMatrix.cpp Timer.cpp -o InvertMatrix
```

## Запуск

### 1. Генерация тестовых данных
```bash
# Создает файлы M1.dat и M2.dat со случайными матрицами 2000×2000
./Matrixes_Generator

# Создает файл T1.dat с трехдиагональной матрицей
./GenerateMatrix
```

### 2. Выполнение операций с матрицами
```bash
# Сложение матриц M1 + M2 → M3.dat
./Sum_Matrices_Sequential

# Умножение матриц M1 * M2 → M3.dat
./Multiply_Matrices

# Инверсия трехдиагональной матрицы T1.dat → T2.dat
./InvertMatrix
```

## Выходные данные

Каждая программа выводит:
- Время выполнения операции
- Сообщение "I am FASTEEER!"
- Сохранение результатов в файлы:
  - `M3.dat` - результаты сложения/умножения
  - `T2.dat` - результат инвертирования

## Требования

- **Процессор**: с поддержкой AVX2 инструкций
- **Память**: минимум 8GB RAM (для матриц 2000×2000)
- **ОС**: Linux/Unix-подобная система
- **Компилятор**: GCC с поддержкой C++11

## Проверка поддержки AVX

Чтобы проверить, поддерживает ли ваш процессор AVX2:
```bash
grep avx2 /proc/cpuinfo
```

Если команда выводит список флагов - процессор поддерживает необходимые инструкции.

**Примечание**: Для достижения максимальной производительности убедитесь, что фоновые процессы не нагружают систему во время выполнения тестов.
